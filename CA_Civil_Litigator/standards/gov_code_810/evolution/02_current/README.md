# Evolution Stage 02: Current

The current text of Gov. Code §810 is at `../../current/gov_code_810_leginfo.txt`.

## Summary of current state

§810 itself is unchanged from 1963 in substance. Subdivision (b) — naming the division as the "Government Claims Act" — was added by Stats. 2016, Ch. 31 (SB 836). Before that amendment, the division was commonly called the "California Tort Claims Act" or the "Government Claims Act" informally. The 2016 amendment codified the name.

## The framework as it stands today

The Government Claims Act has been amended many times since 1963, but the core architecture remains:

1. **No common-law liability for public entities** (§815) — liability only where statute provides
2. **Vicarious liability** (§815.2) — entity liable for employee torts within scope of employment
3. **Specific immunities** (§§818-825.6) — discretionary acts, emergency services, etc.
4. **Claim presentation** (§§900-915.4) — must file tort claim before suing; 6-month deadline for most claims, 1-year for certain claims
5. **Late claim relief** (§§911.4-912.2) — courts can grant leave to file a late claim for good cause
6. **Defense and indemnification** (§§995-996.6) — public entities defend and indemnify employees

## Key amendments since 1963

- Multiple amendments expanding and narrowing specific immunities
- Changes to claim filing deadlines and late-claim procedures
- The 2016 naming amendment (SB 836)
- Various amendments responding to specific court decisions

## What has NOT changed

The fundamental structure — statutory liability, vicarious liability, claim presentation, specific immunities — is the same architecture the Law Revision Commission designed in 1963. The amendments have adjusted details within the framework; they have not replaced the framework.
