# Statute Version Cited: Pre-Statutory -- Gov. Code 810 Did Not Yet Exist

## The Relevant Text

Muskopf was decided in 1961. Gov. Code 810 was enacted in 1963 as part of the Government Claims Act (Stats. 1963, Ch. 1681). There was no statute to cite -- the court was abolishing the common law doctrine of sovereign immunity that had existed without any statutory basis.

## What the Legislature Did in Response

After Muskopf, the Legislature created the entire Government Claims Act framework:

- **Gov. Code 810**: Definitions and scope -- "This part governs the liability of public entities and public employees."
- **Gov. Code 815**: Public entities are not liable except as provided by statute (no common law tort liability for public entities).
- **Gov. Code 815.2**: Public entities are vicariously liable for the torts of their employees committed within the scope of employment.
- **Gov. Code 818-825.6**: Specific immunities for specific types of governmental conduct.

## Why This Matters

Gov. Code 810 cannot be understood without understanding that it was born from Muskopf. The Legislature was not granting liability -- the court had already done that. The Legislature was creating a structured framework to manage the liability that Muskopf had opened up. The Act is the Legislature's answer to Muskopf, not a restoration of the immunity Muskopf abolished.

## Source

Muskopf predates the statute. Gov. Code 810 et seq. was enacted by Stats. 1963, Ch. 1681. Current version available at leginfo.legislature.ca.gov.
