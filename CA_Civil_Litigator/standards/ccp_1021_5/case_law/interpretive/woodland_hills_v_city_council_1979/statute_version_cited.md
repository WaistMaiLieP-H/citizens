# Statute Version Cited

Woodland Hills was decided in 1979. The court was reading CCP §1021.5 as originally enacted by Stats. 1977, Ch. 1197 (S.B. 947), effective January 1, 1978. This was the first version of the statute — only about a year old when this case was decided.

The current text at `current/ccp_1021_5_leginfo.txt` has been amended since 1979, including restrictions on fee awards against public entities, but the core three-factor framework from Woodland Hills still governs the current statute.
