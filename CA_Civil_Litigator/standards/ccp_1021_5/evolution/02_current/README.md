# Evolution Stage 02: Current

The current text of CCP 1021.5 is at `../../current/ccp_1021_5_leginfo.txt`.

The statute has been amended several times since its 1977 enactment, primarily to address fee-shifting involving public entities and to incorporate the Serrano multiplier limitation. The current text reflects all amendments through 2026.

Key changes from origin:
- Added limitation that fees run against but not in favor of public entities
- Added prohibition on Serrano multiplier for fee awards against public entities
- Clarified that no government tort claim filing is required for fee motions

The core three-part test -- significant benefit, necessity and financial burden, fees not from recovery -- has remained unchanged since 1977.
