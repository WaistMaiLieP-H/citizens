# Actors — CA Civil Litigator

Local actor records for this Citizen's domain. Each file contains the actor's role and exposure **within California general civil litigation only** (Government Claims Act, MICRA, CCP tort claims).

The full cross-domain record for each actor lives in the shared registry at `${citizens}/_shared_actors/`. The `shared_record` field in each JSON points there.
