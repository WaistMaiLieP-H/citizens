# Statute version cited in In re Marriage of Walker (2012)

*Walker* applied Fam. Code §§ 1100 and 1101 as they existed in 2012. The substantive content of §§ 1100(e) and 1101(h) has been stable since the 1991 amendments to former Civ. Code § 5125/§5126 and the 1992 Family Code recodification. The 2012 version is identical to the 2026 version.

**Subdivisions construed:**
- Fam. Code § 1100(e) — spousal fiduciary duty with full-disclosure obligation
- Fam. Code § 1101(h) — 100%-of-value remedy for breaches constituting fraud, oppression, or malice under Civ. Code § 3294
- Fam. Code § 1101(g) — attorney's fee sanctions for breaches
- Fam. Code § 721 — general spousal fiduciary duty (cross-reference)

**Consistency check:** The *Walker* opinion quotes § 1100(e) and § 1101(h) accurately. The quoted text matches 2026 current text. No drift.
