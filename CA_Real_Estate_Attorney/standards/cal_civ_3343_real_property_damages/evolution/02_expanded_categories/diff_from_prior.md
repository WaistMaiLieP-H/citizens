# Diff from Stage 01 (1872 Original) to Stage 02 (Expanded Categories)

## Added
- Subdivision (a) designation and "including any of the following:" lead
- (a)(1): Reliance expenditures category
- (a)(2): Loss of use and enjoyment category
- (a)(3): Lost profits from induced-to-sell scenarios
- (a)(4): Lost profits from induced-to-buy scenarios (with strict proof requirements (i)–(iii))
- Subdivision (b) with two explicit prohibitions: (b)(1) no benefit-of-bargain; (b)(2) equitable remedies preserved

## Unchanged
- Core out-of-pocket measure: "difference between the actual value of that with which the defrauded person parted and the actual value of that which he received" — this language was preserved verbatim.
- "Together with any additional damage arising from the particular transaction" — this language was preserved and expanded by making the four categories specific instances of "additional damage."
