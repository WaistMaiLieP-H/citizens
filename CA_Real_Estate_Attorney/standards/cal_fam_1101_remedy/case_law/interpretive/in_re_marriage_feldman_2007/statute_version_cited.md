# Statute version cited in In re Marriage of Feldman (2007)

*Feldman* applied Fam. Code §§ 721, 1100, and 1101 as they existed in 2007. These sections have been substantively stable since the 1994 Family Code recodification, with the 1991 fiduciary duty language fully incorporated. The 2007 version is identical to the 2026 current text on all relevant provisions.
