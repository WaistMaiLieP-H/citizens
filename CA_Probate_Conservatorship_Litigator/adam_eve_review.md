## Critical Legal Findings (EVE Certification)

These findings are certified by this dual witness review and may be relied upon
in pleadings with the following verification caveats:

1. **CERTIFIED:** An UNMARRIED 14-year-old CANNOT be conserved under Prob. Code §1800.3(a)(2). Any Prob. Code conservatorship of person over an unmarried minor was entered without statutory authority and is void.

2. **CERTIFIED:** WIC §5350(a) allows LPS conservatorship of any gravely disabled minor — this is the only statutory pathway for conservatorship of an unmarried minor's person.

3. **CERTIFIED:** WIC §5350(f) explicitly exempts LPS conservatorship from Prob. Code §1826 investigator interview requirements and §1851 annual review requirements. Absence of §1826/§1851 records does not mean the conservatorship does not exist — it means LPS was the likely pathway.

4. **CERTIFIED:** §5350(e): A person is NOT gravely disabled if willing family/friends can help them survive safely without detention — and state so in writing. If no one was offered this opportunity before the LPS conservatorship was established, the §5350(e) defense was never applied.

5. **CERTIFIED:** §1800.3(b): Every conservatorship order must contain an EXPRESS FINDING that conservatorship is the least restrictive alternative. Absence of this finding from the GC-340 order is a structural defect in the order.
