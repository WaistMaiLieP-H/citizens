# Historical Chain — Pen. Code § 166 (Criminal Contempt)

| Year | Event | Significance |
|---|---|---|
| 1872 | Pen. Code § 166 enacted (original form — narrower scope) | Codified common-law contempt |
| 1970s-80s | DV protective order enforcement crisis | Background for later enhancements |
| 1989-1990 | Subd. (c) DV protective order enhancement enacted | First specific category enhancement |
| 1993 | Subdivisions (b) and (c) expanded; enhanced penalties for repeat violations | Strengthening |
| 2000s-2010s | Gang injunction (subd. (a)(9)) added; social media contact enhanced | Modern expansions |
| 2020s | Current form with electronic communication provisions | Digital-era updates |
| 2026 | In force | Active enforcement tool |

## The wound

Pre-1989 California had civil contempt but weak criminal contempt for DV cases specifically. DV restraining orders were issued but poorly enforced — abusers who violated the orders faced only civil contempt (often resulting in nothing more than a stern warning). Victims continued to be harmed because the restraining order system had no criminal teeth. The 1989-1990 amendments added subd. (c) to create specific criminal consequences for DV protective order violations.

## The promise

Section 166 today promises: **court orders in the categories listed in subd. (c) carry criminal penalties that escalate with repeat violations and serious consequences**. The promise is only as good as the prosecution's willingness to charge, which varies by jurisdiction. Domestic violence cases remain the most litigated category under subd. (c).

## Relevance

Section 166 is a supporting statute in the Criminal Law Specialist's corpus. It is not a primary charge in 04-23-01959 (that is § 273a) but is relevant to the broader family-law history and to any instance where court orders have been violated by any party.
