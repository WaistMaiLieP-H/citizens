# Statute version cited in People v. Chaklader (1994)

The *Chaklader* court applied Pen. Code § 148.5(a) as it existed in 1994. The scienter element ("knowing the report to be false") has been stable since the original 1933 enactment, with minor textual refinements. The 1994 version of § 148.5(a) is substantively identical to the 2026 current text on the knowing-falsity element.

**Consistency check:** The *Chaklader* court's analysis of the scienter element (requiring actual knowledge, provable by circumstantial evidence, defeated by honest mistake) applies with identical force to current § 148.5 prosecutions. No textual drift.
