Cal. Penal Code § 995 — Original Codification (1872)
California Penal Code enacted March 12, 1872 (effective April 1, 1872)

The 1872 codification set the foundational text:

"§ 995. When the indictment or information must be set aside.
The indictment or information must be set aside by the court in which the defendant is arraigned, upon his motion, in either of the following cases: ...
2. If it is an information: that before the filing thereof the defendant had not been legally committed by a magistrate."

The 1872 version established the core principle: an information may be challenged if the defendant was not properly committed (no probable cause finding) at the preliminary hearing. This is a due process protection — the defendant has the right to demand that the prosecution prove probable cause before the case proceeds to trial.

The California Penal Code of 1872 was a comprehensive codification modeled on the Field Code (New York). The drafters of the 1872 California Code incorporated the preliminary-hearing / probable-cause foundation that had been established in earlier California jurisprudence dating to the 1850s.

Source: California Penal Code, enacted March 12, 1872.
