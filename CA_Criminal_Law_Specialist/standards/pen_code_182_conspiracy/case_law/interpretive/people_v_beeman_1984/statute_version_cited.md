# Statute version cited in People v. Beeman (1984)

*Beeman* applied § 182 as it existed in 1984. The specific intent element construed in *Beeman* is unchanged by any amendment since that date — the dual intent requirement is a function of the conspiracy statute's core structure, which has been stable since 1872.

**Consistency check:** *Beeman*'s dual intent holding applies directly to current § 182 cases without any amendment-related concern.
