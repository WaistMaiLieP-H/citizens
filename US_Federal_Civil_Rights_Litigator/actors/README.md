# Actors — US Federal Civil Rights Litigator

Local actor records for this Citizen's domain. Each file contains the actor's role and exposure **within federal civil rights law only** (42 USC §1983, §1985, §1988).

The full cross-domain record for each actor lives in the shared registry at `${citizens}/_shared_actors/`. The `shared_record` field in each JSON points there.
