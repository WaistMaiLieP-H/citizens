# §1028A — Diff: Pre-Dubin vs. Post-Dubin

## Textual change: NONE
The statute text was not amended. Dubin is a judicial interpretation of existing statutory language.

## Logical architecture change

| Dimension | Pre-Dubin (2004–2022) | Post-Dubin (2023–present) |
|---|---|---|
| Trigger threshold | Any use of real person's ID during a predicate offense | Identity use must be "at the crux" of what makes the conduct criminal |
| Healthcare fraud | §1028A attached to any billing using patient IDs | §1028A does NOT attach unless impersonation or account-takeover |
| Benefits fraud | §1028A attached to any SS/Medicare claim using beneficiary's ID | Same narrowing — administrative use ≠ at-the-crux |
| Account takeover | §1028A applied | §1028A still applies — this is a core §1028A case |
| Synthetic identity/impersonation | §1028A applied | §1028A still applies — this is the paradigm §1028A case |
| Circuit split | 4th, 6th, 11th: broad reading; 1st, 2nd: narrower | All circuits: Dubin's "at the crux" standard controls |

## What Dubin did NOT change

1. The mandatory consecutive nature of §1028A sentences — still mandatory, still consecutive
2. The §1028A(b)(4) anti-stacking rule — still controls multi-count situations
3. The Flores-Figueroa knowledge requirement — defendant must know the ID belongs to a real person
4. The enumerated predicate list — §1028A(c) unchanged
5. The 2-year minimum (§1028A(a)(1)) and 5-year terrorism minimum (§1028A(a)(2))

## Operational implication for referral cases

When making a criminal referral that includes §1028A:
- Describe the identity use in terms of Dubin's "at the crux" framework
- Emphasize: **the fraud would not have succeeded without the identity taking**
- Document the point of account origination or account takeover — that is the at-the-crux moment
- Distinguish any Dubin-style administrative use argument in the referral package
