# Provenance — Cal. Pen. Code § 13701

## Statute Origin

**Code:** California Penal Code
**Section:** 13701
**Title:** Law Enforcement Domestic Violence Response — Written Policies

**Original Enactment:** Enacted as part of California's early domestic violence reform legislation; mandatory compliance date set at January 1, 1986.

**Legislative Purpose:** The Legislature found that domestic violence was treated as a lesser crime and that law enforcement responses were inconsistent and inadequate. § 13701 was enacted to mandate uniform, written, publicly available policies ensuring DV calls receive the same professional response as any other violent crime call.
