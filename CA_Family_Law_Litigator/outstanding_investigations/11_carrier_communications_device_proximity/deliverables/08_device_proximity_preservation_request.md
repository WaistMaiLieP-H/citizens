## CONTEXT

The phrase "**device access requiring physical proximity**" in the underlying investigation is structurally consistent with:
- Apple's **Stolen Device Protection** (physical-proximity-dependent security delay)
- Apple's **Find My / Activation Lock** (physical-device + carrier-SIM coupling)
- Google's **Find My Device / Account Recovery** (trusted-device physical tokens)
- Google's **2-Step Verification prompts** (trusted device physical tap)
- Microsoft **Authenticator / Windows Hello for Business** (physical-device cryptographic attestation)
- Samsung **Knox / Secure Folder / SmartThings Find** (physical-device enrollment)

If the steward's devices were ever accessed by a third party via in-person physical presence (store visit, warranty swap, repair center, forensic imaging), these platforms hold the authoritative logs.
