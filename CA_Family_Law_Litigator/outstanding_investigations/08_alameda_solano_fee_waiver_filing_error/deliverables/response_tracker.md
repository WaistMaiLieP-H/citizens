## Follow-up protocol

1. **Preserve the 5-day clock.** CRC Rule 3.52(a) requires a ruling on a fee waiver application within 5 court days. If the clerk cannot show a timely FW-003, the application is deemed granted (Gov. Code § 68634(e)). Document the filing date and count court days explicitly.
2. **If clerk refuses to make ministerial correction:** obtain the refusal in writing, or memorialize in a contemporaneous declaration signed same day.
3. **If Alameda claims the file was transferred but Solano disclaims receipt:** request both (a) Alameda's transmittal log and (b) Solano's intake log; the mismatch itself is evidentiary.
4. **If either court invokes confidentiality for FW-002 supplements:** confirm the steward (as the filing party) has full access to his own FW-002 (Gov. Code § 68633(d)).
