# Conservatorship Investigation Workflow

## Intake → Analysis → Synthesis → Work Product

---

### Phase 1: INTAKE — Establish Whether a Conservatorship Exists

**Trigger:** Steward reports evidence consistent with conservatorship (managed existence, controlled finances, restricted communications, identity anomalies)

**Actions:**
1. Search probate court records in ALL relevant counties:
   - Contra Costa County Superior Court (current residence)
   - Alameda County Superior Court (prior residence, Oakland PD jurisdiction)
   - San Francisco County Superior Court
   - Solano County Superior Court (Benicia)
   - Any county where the mother, Christina, or Cole have resided
2. Search by: steward's legal name(s), SSN (if court system allows), date of birth
3. Search for: conservatorship petitions, guardianship petitions, LPS petitions
4. Document: case number, filing date, petitioner, proposed conservator, court assigned

**Output:** EXISTENCE DETERMINATION — yes (with case details) or no (with search documentation)

**If NO:** Investigation pivots to alternative explanations for the control pattern. Stop this workflow.
**If YES:** Proceed to Phase 2.

---

### Phase 2: ANALYSIS — Audit the Conservatorship Against §1801-§2620

**Actions (for each checkpoint):**

| Checkpoint | Standard | Question | Document to Obtain |
|---|---|---|---|
| Capacity | §811 | What mental function deficit was identified? Was correlation shown? | Capacity declaration (GC-310) |
| Least Restrictive | §1800.3 | Did the court find conservatorship was least restrictive? Were alternatives considered? | Order of appointment (findings) |
| Grounds | §1801 | Which subdivision — (a) person, (b) estate, (c) both, (d) limited? Clear and convincing evidence? | Petition + supporting declarations |
| Investigation | §1826 | Was the steward personally interviewed? Informed of rights? Medical reports from his own doctors? | Court investigator's report |
| Hearing Rights | §1828.5 | Was the steward told what was happening? Asked his opinion? | Minute order from hearing |
| Ongoing Review | §1851 | Have surprise visits been conducted? Was the steward told he's under conservatorship? | §1851 review reports (all of them) |
| Accounting | §2620 | Has the conservator filed accountings? Are they complete? Where did the money go? | All filed accountings + supporting documents |
| Termination | §1860/1863 | Can this be terminated now? Burden is on the conservatorship. | N/A — this is the steward's action |

**For each checkpoint:** Document what SHOULD have happened (the standard), what DID happen (the record), and the DEFICIENCY (what was skipped or done wrong).

**Output:** CHECKPOINT AUDIT — a table of pass/fail for each standard with specific deficiencies documented.

---

### Phase 3: SYNTHESIS — Connect Conservatorship to the Control Pattern

**Actions:**
1. Map conservator's documented powers against the documented control pattern:
   - Property control → house sale, financial transactions, crypto
   - Medical authority → spine surgery authorization, SIRVA treatment decisions, SSA/DDS interactions
   - Communication control → SIM swap, call interception, service provider impersonation
   - Residence control → managed living situation
   - Identity control → "retired" status, pension freeze, SSN usage
2. For each control element, determine: was conservator authority the legal mechanism, or was the control extralegal?
3. Cross-reference with other Citizens' findings:
   - Civil rights violations → Bane Act / §1983
   - Medical privacy violations → CMIA §56.10
   - Document authentication failures → Evidence Code §1400
   - Property fraud → recording acts / community property

**Output:** CONTROL PATTERN MAP — linking each documented harm to either (a) conservator authority (legal mechanism) or (b) unauthorized action (fraud/civil rights violation)

---

### Phase 4: WORK PRODUCT — Generate Actionable Documents

**If conservatorship exists and deficiencies found:**
1. **Petition for termination** (§1861) — citing §1863's clear-and-convincing-evidence burden on the conservatorship
2. **Request for accounting** — demanding all §2620 accountings and supporting documents
3. **PRA request** to the court for all §1826 and §1851 investigator reports
4. **Complaint** — §1983 (federal, if state actors involved) + Bane Act (state) + CMIA (medical privacy) + fraud claims

**If conservatorship does NOT exist:**
1. Document the search and its negative result
2. Pivot investigation to alternative mechanisms for the control pattern
3. Generate complaint based on the control pattern without conservatorship as the mechanism

---

### Handoff Protocol

At the end of each phase, the Conservator Investigator produces a deliverable and hands off to the appropriate Citizen for the next step:

- Phase 1 output → Conservator Investigator Phase 2
- Phase 2 output → Conservator Investigator Phase 3
- Phase 3 output → ALL relevant Citizens for parallel work product generation
- Phase 4 output → Steward for review and filing decisions
