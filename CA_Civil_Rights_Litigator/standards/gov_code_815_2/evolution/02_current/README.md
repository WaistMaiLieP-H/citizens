# Gov. Code § 815.2 — Current Status

## Amendment history

None. The text of Section 815.2 is unchanged since its enactment in 1963 as part of the California Tort Claims Act.

Two subdivisions. Sixty-three years. No amendments.

## Current text

The current text is captured in `../current/gov_code_815_2_text.txt`, fetched from leginfo.legislature.ca.gov via VernenLegal MCP on 2026-04-09.

## Why it has never been amended

Section 815.2 states a simple, foundational principle: the employer is liable for the employee's wrongs on the job. There is nothing to expand, refine, or modernize. The immunities that limit it live in other sections (Government Code Sections 818, 820.2, 821, etc.) — those have been amended. The vicarious liability principle itself has not needed to change.
