# Diff from Prior Stage

**Prior:** 02_amendment_1974 — disability added to enumerated categories
**This stage:** 03_amendment_1992 — ADA violation = automatic Unruh violation

## Key Changes

1. **Added (f):** Any ADA violation constitutes an Unruh Act violation
2. **Effect:** Federal disability access standards enforceable in state court with Unruh's superior remedies ($4,000+ statutory damages per violation)

## Practical Impact

| Federal ADA claim | Unruh Act via ADA incorporation |
|---|---|
| Federal court | State court available |
| No minimum statutory damages | $4,000 minimum per violation |
| Injunctive relief primary remedy | Damages + injunctive relief |
| Limited fee-shifting | Attorney's fees under §52 |

The incorporation provision made California the most plaintiff-friendly jurisdiction for ADA enforcement.
