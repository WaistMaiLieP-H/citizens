# Cal. Civ. Code § 52 — Current State

## Pointer

The current text of §52 is at `../../current/`. The statute has been amended incrementally over decades as California's civil rights framework expanded.

## Evolution Summary

§52 is a remedies provision that has grown with the substantive statutes it enforces. Key expansion points:

| Period | Event | Impact on §52 |
|---|---|---|
| 1959 | Unruh Act enacted | Original remedies for §51 violations |
| 1976 | Ralph Act enacted | Added §51.7 remedies (§52(b)): exemplary damages + $25,000 civil penalty |
| 1980s–90s | §51.5, §51.6, §51.9 added | §52(a) expanded to cover new companion statutes |
| 1990s | $4,000 minimum | Statutory damages floor raised to current $4,000 per violation |
| 2000s | Government enforcement | AG/DA/city attorney enforcement powers strengthened |
| 2010s | Anti-waiver, CRD option | Added administrative complaint path + contract anti-waiver |

## The Remedial Architecture

§52 serves the same structural function as 42 USC §1988 in federal civil rights law: it makes civil rights enforcement economically viable. Without §52's $4,000 minimum + attorney's fees, most individual discrimination incidents would be too small to litigate. The remedies provision is what converts the substantive rights (§51, §51.7, §52.1) from paper promises into enforceable guarantees.

| Violation Type | Actual Damages | Statutory/Penalty | Treble | Fees |
|---|---|---|---|---|
| Unruh Act (§51) | Yes | $4,000 minimum | Up to 3x | Yes |
| Ralph Act (§51.7) | Yes | $25,000 civil penalty | — | Yes |
| Ralph Act (§51.7) | Yes | Exemplary damages (no cap) | — | Yes |
