# Cal. Civ. Code § 52 — Current Status

## Amendment history

Section 52 has been amended many times since its original enactment. Key amendments have:

- Expanded the statutes covered (adding Section 51.5, 51.6, 51.7, 51.9 over time)
- Increased the statutory damages minimum (now $4,000)
- Added the Ralph Act civil penalty ($25,000)
- Added government enforcement provisions (AG, DA, city attorney actions)
- Added the administrative complaint option through the Civil Rights Department
- Added the anti-waiver provision (subdivision (i))
- Clarified that "actual damages" includes both special and general damages
