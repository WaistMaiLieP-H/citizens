| Standard ID | Authority | Connection | Type |
|---|---|---|---|
| FRE_602 | FRE 602 | Personal knowledge — hearsay and personal knowledge are parallel reliability gates; FRE 602 asks "did you observe it?"; hearsay asks "is this an out-of-court statement offered for truth?" | Parallel gate |
| FRE_901 | FRE 901 | Authentication — before a document can be admitted as a business record (FRE 803(6)) or public record (FRE 803(8)), it must be authenticated under FRE 901 | Authentication predicate |

| CAL_EVID_1235 | Cal. Evid. Code § 1235 | California prior inconsistent statements — broader than FRE 801(d)(1)(A) in California; prior inconsistent statements are substantive evidence even without oath | California parallel |
| CAL_EVID_1200 | Cal. Evid. Code § 1200 | California hearsay rule — parallel to FRE 802; governs state court proceedings | California parallel |
| USC_28_1746 | 28 U.S.C. § 1746 | A § 1746 declaration is an out-of-court statement. When offered in evidence, it is hearsay UNLESS it falls within an exclusion or exception — most commonly FRE 801(d)(2) (party admission) or is the declarant's own sworn testimony submitted under FRCP 56(c)(4) | Declaration hearsay status |

## The Hearsay Decision Tree HERALD Uses

```
1. Is this an assertion (verbal, written, or intended nonverbal)?
   NO → Not hearsay (e.g., operative legal acts, verbal performance)

2. Was it made out of court?
   NO → Not hearsay (live testimony)

3. Is it offered to prove the truth of what it asserts?
   NO → Not hearsay. Admitted for: notice, effect on listener, verbal act, 
         impeachment, showing statement was made (not truth of content)

4. Does it qualify as "not hearsay" under FRE 801(d)?
   YES (party admission or prior statement) → Admissible, not hearsay

5. Does it fit a FRE 803 exception (declarant availability immaterial)?
   YES → Admissible despite hearsay

6. Is declarant unavailable AND does it fit a FRE 804 exception?
   YES → Admissible despite hearsay

7. Does it satisfy the FRE 807 residual exception (trustworthiness + materiality + 
   most probative + justice + notice)?
   YES → Admissible despite hearsay

ELSE → HEARSAY — EXCLUDED
```
