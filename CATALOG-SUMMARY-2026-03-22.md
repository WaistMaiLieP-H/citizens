## Core Architecture

CUSTOS (CITIZEN-019) — Legal Intake Guardian
- Every document passes through CUSTOS first
- Three-step protocol: Interception, Verification, Statutory Shield
- "This document is now GOVERNED BY VERNEN"

Triple Constraint (applied to every persona):
1. Governing Guidelines — Is it legal? (statutes, regulations)
2. Standards of Creation — Is it genuine? (professional standards, formatting)
3. System & Organization Controls — Is it untampered? (chain of custody, integrity)

Document Is The Instruction:
- No user input required
- Submission IS consent
- Every document gets EVERYTHING — every applicable framework, every flag
- 6,400 documents per second
