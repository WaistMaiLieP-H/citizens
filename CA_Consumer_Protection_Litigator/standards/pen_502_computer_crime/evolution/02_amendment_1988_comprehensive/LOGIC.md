# Evolution Stage 02 — 1988 Comprehensive Rewrite: Modern §502

### THE WOUND

By 1988, the personal computer revolution had fundamentally changed the landscape.
The 1979 statute's narrow focus on mainframe access did not address:
- PC-based networks and home computers
- Corporate espionage through computer access
- Hacking for financial gain
- The increasing commercial value of stored data
- Civil remedies for computer crime victims

The Legislature found the 1979 statute "inadequate to address the many forms of
harm that can occur through unauthorized computer access and use."

### DESIGN RESPONSE — 1988

Stats. 1988, Ch. 1523 completely rewrote §502. Key design decisions:

**Comprehensive definition framework:** §502(b) added detailed definitions of "access,"
"computer," "computer network," "computer services," "computer system," "data,"
"disruption," and "without permission." This definitional infrastructure established
the vocabulary for all subsequent computer crime analysis.

**Multiple prohibited act categories:** §502(c) enumerated specific prohibited acts
covering fraud, unauthorized access, service theft, and disruption. The breadth ensured
coverage across the full range of computer crime scenarios.

**Civil action added (§502(e)):** For the first time, California computer crime law
included an explicit civil remedy — compensatory damages, injunctive relief, and
(with criminal conviction) $5,000 per violation civil penalty.

**"Without permission" as operative standard:** §502(b)(12) defined "without permission"
as access not explicitly authorized by the owner, lessee, or authorized user. This is
a simpler standard than the CFAA's "without authorization / exceeds authorized access"
framework — California's "without permission" is more plaintiff-favorable.

**No interstate commerce requirement:** Unlike the CFAA (which requires the computer
to "affect interstate commerce"), California §502 covers any computer, computer system,
or computer network in California. The state's interest in protecting California
computer users is sufficient jurisdictional basis.

### LOGICAL DELTA

| Element | 1979 (original) | 1988 (comprehensive rewrite) |
|---------|-----------------|------------------------------|
| Scope | Narrow mainframe focus | Broad: all computers, networks, data |
| Definitions | Minimal | Comprehensive §502(b) framework |
| Prohibited acts | Few categories | 8+ enumerated categories §502(c)(1)-(c)(8) |
| Civil remedy | None | §502(e): compensatory + injunctive + penalty |
| Interstate commerce | Not required (but limited scope) | Not required (broader coverage) |
| CFAA parallel | N/A (CFAA not yet enacted) | Parallel to federal CFAA; covers cases where CFAA threshold not met |

### PROVENANCE

Stats. 1988, Ch. 1523
Complete rewrite of Cal. Penal Code §502
Effective January 1, 1989
