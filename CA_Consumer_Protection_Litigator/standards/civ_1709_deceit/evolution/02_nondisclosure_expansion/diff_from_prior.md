# §§1709-1711 — Diff: 1872 Original vs. Post-Lovejoy

| Dimension | 1872 Original | Post-Lovejoy (2004+) |
|---|---|---|
| Statutory text | Unchanged | Unchanged |
| "Bound to disclose" standard | Undefined — common law only | Lovejoy four-category framework |
| Exclusive knowledge duty | Recognized but undefined | Category 2 — clearly established |
| Active concealment duty | Implicit in §1710(3) | Category 3 — explicitly recognized |
| Partial representation duty | Uncertain | Category 4 — clearly established |
| Promissory fraud | §1710(4) text | Unchanged — Lovejoy supplements but does not alter |
| Out-of-pocket damages | §3343 rule | Unchanged — still out-of-pocket |
| SOL | CCP §338(d) 3 years | Unchanged |
| Punitive damages interaction | §3294 (enacted later) | Unchanged relationship |

## Summary

The only evolution in this standard is judicial — Lovejoy populated the "bound to disclose"
category that was left undefined in 1872. The statutory text, the damages rule, the SOL, and
the punitive damages interaction are all unchanged.

For Michael's auto fraud cases: the nondisclosure-expansion (Lovejoy categories 2, 3, and 4)
is the mechanism by which the dealer's failure to disclose known prior damage, provision of
a false CARFAX, and promissory fraud about financing terms give rise to §1709 deceit liability.
