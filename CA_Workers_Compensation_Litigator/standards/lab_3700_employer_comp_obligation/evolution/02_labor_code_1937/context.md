# LAB §3700 — Stage 02: Labor Code Recodification 1937

**Stage:** 02_labor_code_1937

Recodified as Lab. Code §3700 in the 1937 Labor Code. The three-path coverage structure was carried over. The "state" exception was added (state as sovereign employer is self-insured by operation of law, not by DIR certificate). Text has been refined through subsequent amendments but the three-path structure has remained constant.
