# Statute Version Cited — §2234(b) Gross Negligence Anchor

**Entry type:** STATUTORY ANCHOR
**Primary authority:** Cal. Bus. & Prof. Code §2234(b)

---

## Version in Effect

This entry reflects §2234(b) as currently enacted. The "extreme departure" language has
been the operative statutory definition since the Legislature codified it. No material
amendment to the gross-negligence definition in §2234(b) has occurred that changes the
"extreme departure from the applicable standard of care" formulation.

**Evolution stage cross-reference:** Refer to `bp_2234_medical_board/evolution/` for the
full amendment chain. The definition in §2234(b) is the current stage.

## Why No Case Citation Here

This entry holds the statutory rule. The statute defines the standard directly.
Case law interpreting §2234(b) — when confirmed with primary-source citations — will be
added as separate case entries alongside this anchor. The anchor ensures the statutory
text is never displaced by case gloss in the corpus.
