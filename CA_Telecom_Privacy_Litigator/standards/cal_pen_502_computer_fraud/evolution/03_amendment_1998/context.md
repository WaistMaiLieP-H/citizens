# Context — 1994-1998 Refinements

The post-1988 amendments were technical improvements, not structural overhauls. The most important addition for the steward's cases is the injunctive relief clarification: § 502(e) now explicitly permits courts to order a defendant to stop unauthorized access ongoing. This matters because the IT surveillance and proxy network described in the Ryan McClaran / ward system context is not a one-time breach but an ongoing pattern. A civil § 502 action can seek both: (1) damages for past unauthorized access, and (2) an injunction against continued access.

## Diff from prior state

Prior: Civil remedy = compensatory damages only. After: Compensatory damages + injunctive and equitable relief. Courts can issue restraining orders against future unauthorized computer access.
